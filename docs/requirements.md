# Library Management System Requirements

## 1. Project Goal

The application manages a library's books through a web interface.

## 2. Core Features

- Add a new book
- Display a list of books
- Display the details of one book
- Edit an existing book
- Delete one book
- Search books
- Filter books
- Select multiple books
- Delete multiple selected books

## 3. Optional Features

- User management
- Book categories

## 4. Main Entity

The main entity of the first version is:

- Book

## 5. Initial Book Fields

The exact fields will be finalized before model implementation.

## 6. Non-Functional Requirements

- The project must use Django.
- The project must use Git.
- The application must provide server-side form validation.
- Destructive actions must require confirmation.
- The user interface must provide clear success and error messages.

## 7. Scope of the First Version

The first version focuses on book management.

User management and categories will be added only after the core book-management features are complete.
